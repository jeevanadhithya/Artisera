## ⚡ Core Features & Capabilities

### 1. 📸 5-Step Unified Intake Stepper
Replaces dozens of intimidating text form fields with an intuitive 5-step visual flow:
1. **Photo Capture**: Main craft shot with multi-angle capture guidance.
2. **Mother-Tongue Voice Note**: Hold-to-speak recording in native regional language.
3. **AI Enhancement**: Studio isolation on warm ivory background (`#F7F3EA`) with soft shadow.
4. **Interactive Review**: AI-generated bilingual title, story, and tags.
5. **Living Wage Pricing & Publish**: Deterministic fair pricing breakdown and instant Supabase persistence.

### 2. 🗣️ Multilingual Voice Intake (7 Indic Languages)
- Powered by **Sarvam AI** Speech-to-Text hosted on dedicated AWS EC2 instances.
- Supports **Hindi, Tamil, Telugu, Bengali, Marathi, Kannada, and English** with Auto-Detect dialect matching.
- "Polish with Sarvam AI" translates and refines dialect spoken notes into fluent target language listings.
- Integrated Text-to-Speech (TTS) for low-literacy artisans.

### 3. 🧠 Multimodal AI Catalog Synthesis
- Powered by **`Qwen3-VL`** multimodal vision-language model hosted on AWS EC2 GPU instances.
- Analyzes visual features + audio transcript to extract category, craft type, materials, HSN code, and SEO tags.
- Generates an authentic **Cultural Heritage Story** that highlights artisan lineage.

### 4. ⚖️ Fair-Trade Living Wage Pricing Engine
- On-device deterministic formula ensures no artisan sells at a loss:
  $$\text{Fair Price} = \text{Raw Materials} + (\text{Hours Worked} \times \text{Hourly Wage}) + \text{Packaging} + \text{GI Tag Premium} (+20\%)$$
- Interactive sliders let artisans adjust material costs and craft hours with instant price updates.

### 5. 🚀 1-Tap Multi-Marketplace Export
- Direct export dossiers generated on-device without requiring external seller account connections:
  - 📦 **Amazon Karigar**: Flat-file TSV/CSV format.
  - 🏛️ **GeM (Government e-Marketplace)**: Public procurement compliant JSON schema.
  - 🌐 **ONDC (Open Network for Digital Commerce)**: Beckn protocol compatible catalog.
  - 🛍️ **Meesho & Flipkart Samarth**: Social commerce product packs.

### 6. 🎬 Craft Video Reels
- Full-screen vertical swipe video player celebrating traditional crafting techniques.
- Artisan stories, heritage craft origins, and community engagement.

## 🛠️ State Management & Services

- **`LanguageProvider`**: Reactive app-wide language switching across 7 Indic languages.
- **`AuthProvider`**: Supabase Authentication, JWT token management, and dynamic artisan attribution.
- **`CraftProvider`**: Central inventory state, optimistic UI updates, and offline action queue.
- **`ApiService`**: Direct communication with Supabase Storage and PostgreSQL REST endpoints.
- **`ArtiseraVisionService`**: Visual catalog extraction, tag synthesis, and cultural heritage storytelling powered by hosted Qwen3-VL.
- **`ArtiseraSpeechService`**: Sarvam AI Indic speech-to-text integration hosted on dedicated AWS EC2.
- **`ImageEnhancementService`**: Studio lighting isolation pipeline with Remove BG and AWS EC2 BiRefNet fallback.

## 💻 Building from Source

### Prerequisites
- Flutter SDK `^3.13.2`
- Dart SDK `^3.13.2`
- Android Studio / Xcode

### Setup & Run

```bash
# 1. Navigate to Mobile_App directory
cd Mobile_App

# 2. Install Flutter packages
flutter pub get

# 3. Verify code quality (0 errors / 0 warnings)
flutter analyze

# 4. Run on connected device or Chrome
flutter run -d chrome
# or for Android:
flutter run -d android
```

### Building Release APK

```bash
flutter build apk --release
# Built APK will be available at:
# build/app/outputs/flutter-apk/Artisera-v1.0.0-SIH2026.apk
```
